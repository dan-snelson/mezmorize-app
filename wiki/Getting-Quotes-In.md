## Capture

1. Tap + (on a Mac, the + button).
2. Enter the quote and author. The source is optional.
3. Save.

- Applies Memory Method is on by default, and the first review is today.
- Turn it off for quotes you already know. They stay in your collection (Collection Only) and never appear in Today.
- When your collection is empty, choose Add Starter Quotes to add two sample quotes that are due today, so you can try a review right away. On an empty collection, the All and Today tiles show a light gray 2, a preview of the two starter quotes.

## Import from a web page

Paste a web page URL instead of typing. It works best with a link to a single quote or a single scripture verse.

Or share a link to Mezmorize from Safari, Gospel Library, or any app: choose Mezmorize in the Share sheet (the Share menu on a Mac). The page is fetched and the form appears there. Tap Save to add the quote, or Cancel to add nothing.

You can also share one .csv or .mezmorize file to Mezmorize, for example from Files or Finder. The import preview appears there. Choose Import to add the quotes you selected, or Cancel to add nothing. TSV files are not accepted in the Share sheet: use Open With or Import from File… instead.

1. **iPhone and iPad:** touch and hold + and choose Import from URL…. **Mac:** use the + menu or File → Import Quote… (⌘⇧I).
2. Paste the page URL. Mezmorize downloads that one page.
3. Review the New Quote form, which opens already filled in.
4. Tap Save. Nothing is saved until you do.

### What gets filled in

- **A quote page:** the quote, author, and link (and the book when the page names one).
- **A scripture verse (or a range of verses):** the verse text, the volume, and a citation such as 1 Nephi 3:7. The author is left blank.
- **A hymn link:** all the verses, one line per row, the text author, and a title with the hymn’s book and number.
- **A single paragraph of a general conference talk, a magazine article, or a manual:** that paragraph, the speaker as the author, the talk title, and a citation such as October 2026 general conference with the link. Whole talks aren’t imported.
- **A post on X:** the full post text, the author’s name, and the link. For X posts, Mezmorize asks X’s embed service (publish.x.com) for that one post in place of the page. A long post may end with “…” because X shares only its first part. Finish the text in the form before you save.
- **Other pages:** imported on a best-effort basis.

> **Note:** Links that start with http are upgraded to https.

If a site blocks the request, you are offline, or no quote is found, choose Enter Manually.

## Export quotes

1. **Mac:** choose File → Export Quotes… (⌘⇧E). **iPhone and iPad:** use the … menu → Export Quotes… on a quote list.
2. Name the set and tick the quotes.
3. Choose Mezmorize or CSV.
4. Choose Share… (AirDrop, Messages, Mail, Files) or Save to File….

> **Note:** Either file holds only the quote, author, and source, not your review progress or your Applies Memory Method setting. A CSV file opens in Numbers and Excel, and you can import it back into Mezmorize.

## Import from a file

1. Open a .mezmorize, CSV, or TSV file from Mail, Messages, AirDrop, Files, or Finder (on a Mac, Open With → Mezmorize). Or, on a Mac, choose File → Import Quotes from File… (⌥⌘I), or Import from File… in the + menu. Mezmorize is not the default app for CSV or TSV files, so pick it from Open With or the Share sheet.
2. A preview lists every quote with a checkbox. Quotes you already have are marked Already in your quotes and start unticked.
3. Choose Import. Nothing is added until you do.

- In a CSV or TSV file, the first row names the columns. One column must be named Quote, Entry, or Text. Author, Source (or Reference or Citation), and Title are optional. Other columns are ignored.
- CSV and TSV files can be UTF-8 or Windows-1252. The preview shows which columns were used and how many rows were skipped.
- Imported quotes start with the method on. Turn it off for any quote you already know.
- Imported quotes start today. When you import more quotes than the Quotes per day setting in the preview (default 5), they are spread over the following days. Later reviews follow at 1 week, 1 month, 1 quarter, and 1 year from each quote’s start.
